# Annotation Guidelines

This directory contains guidelines for data annotation tasks.

## Documents

- `family_ner_guidelines.md` - Guidelines for family NER annotation
- `ingress_guidelines.md` - Guidelines for ingress/domain classification
- `safety_guidelines.md` - Guidelines for safety band annotation

## General Principles

1. **Consistency**: Follow the guidelines strictly for consistent labels
2. **When in doubt**: Use the conservative option (e.g., higher safety band)
3. **Edge cases**: Document and discuss with team
4. **Quality over quantity**: Accurate labels are more valuable than many labels
